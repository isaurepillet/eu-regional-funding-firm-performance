# Firm-Level Policy Evaluation with Propensity Score Matching

This repository contains exploratory code from an applied research project using **firm-level data** and causal-inference methods.

The analysis focuses on the construction of treatment and control groups and includes preparation for **propensity score matching (PSM)**. The notebooks document data cleaning, geographic enrichment, matching and treatment-group construction.

## Methods

- firm-level data cleaning and matching;
- construction of treatment and control samples;
- geographic data enrichment;
- propensity score matching;
- balance and sample-comparability checks.

## Tools

Python · pandas · Jupyter · causal inference · propensity score matching

## Reproducibility note

This repository originates from a working research environment. Some notebooks contain paths specific to the original Onyxia environment and are retained as research code rather than as a fully reproducible public package.
